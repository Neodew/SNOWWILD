# SnowWild

SnowWild es un juego 2D inspirado en la naturaleza y la vida salvaje. El proyecto busca representar un pequeño entorno natural donde los animales y otros elementos del ambiente puedan comportarse de manera autónoma, creando un mundo que se sienta vivo y dinámico.

La idea principal es que el jugador no vea solamente personajes que siguen movimientos predefinidos, sino un ecosistema donde los animales puedan desplazarse, buscar recursos, alimentarse, descansar, huir de peligros e interactuar con su entorno.

## ¿De qué trata?

SnowWild presenta un mundo natural en 2D en el que diferentes animales forman parte de un ecosistema.

Cada elemento del entorno tiene una función y puede afectar a los demás. La disponibilidad de alimento, el agua, el clima, el tiempo y la presencia de otros animales pueden modificar el comportamiento de la vida salvaje.

El objetivo del proyecto es crear una experiencia sencilla, visual y entretenida, pero al mismo tiempo demostrar cómo puede funcionar un sistema de vida salvaje autónomo dentro de un videojuego.

## Características principales

* Mundo natural en 2D.
* Animales con comportamientos autónomos.
* Exploración de diferentes zonas del entorno.
* Interacción entre animales y naturaleza.
* Sistema de recursos naturales.
* Comportamientos relacionados con alimentación, descanso y peligro.
* Ambiente dinámico.
* Diseño pensado para ser sencillo de entender y jugar.
* Posibilidad de ampliar el mundo y agregar nuevas especies en futuras versiones.

## Idea del sistema

Los animales no dependen completamente de las acciones del jugador.

Cada animal puede tomar decisiones dependiendo de sus necesidades y de lo que ocurre a su alrededor. Por ejemplo, un animal con hambre puede buscar alimento, mientras que otro puede alejarse al detectar un depredador.

Esto permite que diferentes situaciones puedan aparecer de forma natural durante la partida.

## Requisitos

SnowWild está pensado para poder ejecutarse desde cualquier dispositivo compatible con un navegador web moderno.

Se necesita:

* Computadora, laptop, tablet o dispositivo móvil.
* Navegador web actualizado.
* Conexión a Internet.
* JavaScript habilitado en el navegador.

Se recomienda utilizar navegadores actuales como Chrome, Edge, Firefox o Safari.

## Ejecución

El proyecto puede ejecutarse desde el entorno web correspondiente al proyecto.

Una vez cargado, el usuario podrá acceder al juego directamente desde el navegador, sin necesidad de instalar programas adicionales.

## Estado del proyecto

SnowWild se encuentra en desarrollo.

Las primeras versiones están enfocadas en establecer la base del juego, el entorno 2D y el comportamiento de los elementos de la vida salvaje.

Las futuras versiones pueden incorporar nuevas especies, zonas, comportamientos, recursos y mejoras visuales.



## Objetivo

El objetivo de SnowWild es crear un juego 2D sencillo pero interesante, donde la naturaleza tenga un papel importante y la vida salvaje pueda desarrollarse de forma autónoma.

El proyecto también busca servir como una base que pueda seguir creciendo con nuevas mecánicas y contenido.
